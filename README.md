## 📌 Описание

**Cloudflare WARP** (также известный как 1.1.1.1) — это бесплатный VPN-клиент, который шифрует весь ваш интернет-трафик, скрывает ваш IP-адрес и защищает DNS-запросы от слежки.

В отличие от обычных VPN, WARP использует **протокол WireGuard** и **сеть Cloudflare**, что обеспечивает:
- 🚀 Высокую скорость (благодаря умной маршрутизации)
- 🔒 Полное шифрование трафика (не только браузера)
- 🛡️ Защиту от отслеживания и рекламных трекеров
- 🌍 Доступ к глобальной сети Cloudflare (более 300 городов)

### Описание интерфейса

### 1️⃣ Главный экран

- **Статус:** Отображает текущее состояние подключения.
- **Кнопка «Подключить»:** Одно нажатие — и вы под защитой.
- **Режим работы:** Выбор режима VPN (Трафик и DNS, Только DNS и т.д.)
- **Версия клиента:** Актуальная версия программы.

---

### 2️⃣ Режимы работы

Доступны следующие режимы:

| Режим | Описание |
|-------|----------|
| **Трафик и DNS (UDP)** | Полный VPN-туннель. Весь трафик и DNS-запросы идут через Cloudflare. Использует протокол UDP. |
| **Трафик и DNS (TLS)** | То же самое, но с шифрованием TLS (более защищённый, но чуть медленнее). |
| **Только трафик** | Шифруется только интернет-трафик, DNS-запросы остаются локальными. |
| **Только DNS (HTTPS)** | Не шифрует трафик, но защищает DNS-запросы через HTTPS (DoH). |
| **Только DNS (TLS)** | DNS-запросы шифруются через TLS (DoT). |
| **Локальный прокси** | Включает локальный SOCKS5-прокси для выборочного использования. |

---

### 3️⃣ Подключение

- **DNS-подключение:** Показывает статус DNS-защиты.
- **Статус подключения Tunnel:** Отображает состояние VPN-туннеля.
- **Протокол Tunnel WARP:** Тип используемого протокола.
- **Ключи шифрования:** Кнопка «Сбросить ключи» для пересоздания шифрования.

---

### 4️⃣ Настройки

| Раздел | Описание |
|--------|----------|
| **Режим** | Выбор активного режима работы (из списка выше). |
| **Приостановить для сетей Wi-Fi** | Автоматически отключает WARP при подключении к определённым Wi-Fi сетям. |
| **Отключить для всех сетей Wi-Fi** | Полное отключение WARP на всех Wi-Fi сетях. |
| **Отключить для всех проводных сетей** | Отключение WARP на Ethernet-подключениях. |
| **1.1.1.1 для семейного использования** | Включает фильтрацию контента (блокировка вредоносных и взрослых сайтов). |
| **Split Tunnel** | Исключение определённого трафика из VPN-туннеля (например, локальная сеть). |
| **Local Domain Fallback** | Отправка DNS-запросов для локальных доменов на локальный DNS-сервер. |

- **Лицензионный ключ:** Уникальный ключ для активации WARP (можно изменить).

- **Устройства:** Список устройств, на которых используется лицензионный ключ.

## ⚙️ Установка и использование

### Стандартный запуск
1. Скачай клиент с официального сайта Cloudflare или из раздела [Releases](https://github.com/marktesster227/vpn-1.1.1.1/releases).
2. Установи и запусти.
3. Нажми кнопку **«Подключить»** — и вы уже под защитой.

### Настройка режимов
- Открой вкладку **«Настройки»** → **«Режим»**.
- Выбери подходящий вариант (рекомендуется **«Трафик и DNS (UDP)»** для максимальной защиты).

### Использование с локальным прокси
1. В настройках выбери режим **«Локальный прокси»**.
2. В приложениях укажи адрес прокси `127.0.0.1:4000` (по умолчанию).
3. Трафик будет идти через WARP только для выбранных приложений.

### Семейный режим
1. В настройках включи **«1.1.1.1 для семейного использования»**.
2. Выбери уровень фильтрации: только вредоносные сайты или ещё и взрослый контент.

### Технологии
Язык: Rust / Go / C++ (в зависимости от платформы)

### Протокол: WireGuard

### Шифрование: TLS 1.3, постквантовая криптография

### Сеть: Cloudflare Edge Network

### ❓ Часто задаваемые вопросы (FAQ)
Чем WARP отличается от обычного VPN?
WARP не просто скрывает ваш IP и шифрует трафик — он также оптимизирует маршрутизацию через сеть Cloudflare, что делает его быстрее многих традиционных VPN.

WARP бесплатный?
Да, базовый WARP полностью бесплатен. WARP+ (платный) даёт доступ к более быстрой сети.

Безопасно ли это?
Да. Cloudflare — одна из крупнейших компаний в сфере интернет-безопасности. WARP использует шифрование WireGuard и не хранит логи пользователей.

Почему у меня медленный интернет?
Попробуй сменить режим на «Только DNS» или включить Split Tunnel для исключения локального трафика.
